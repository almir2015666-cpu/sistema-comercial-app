Política de Privacidade

CMH Sistema — Clínica Medicina Humana
Última atualização: 19 de setembro de 2026

Este aplicativo ("CMH Sistema") é uma ferramenta interna de gestão usada pela equipe da Clínica Medicina Humana. É a versão de celular do sistema de gestão da clínica (SistemaCMH): os mesmos usuários, permissões e dados. Esta política explica quais dados são tratados ao usar o app.

Quais dados coletamos

  • Dados de login: usuário e senha, e opcionalmente um código de verificação em duas etapas, usados apenas para identificar o colaborador que acessa o sistema.
  • Nome, cargo e setor do colaborador cadastrados pelo administrador do sistema.
  • Dados operacionais da clínica: mensagens da equipe, tarefas, compromissos, chamados de suporte, o controle de serviços protocolados (conferência) e o diário de atividades comerciais, inseridos pelos próprios usuários durante o uso normal do sistema.
  • Registro de acesso: o nome do aparelho e a versão do app a cada entrada, no log de auditoria do sistema. O app não coleta localização nem endereço IP.

Como usamos esses dados

Os dados são usados exclusivamente para o funcionamento do sistema de gestão interna da clínica: controle de agenda, registro de atividades comerciais e controle financeiro. Não usamos os dados para publicidade, não vendemos nem compartilhamos dados com terceiros para fins de marketing.

Onde os dados são armazenados

Os dados são armazenados de forma segura no Supabase (banco de dados PostgreSQL em servidor gerenciado), o mesmo serviço de infraestrutura usado pelo sistema de gestão da clínica para autenticação, banco de dados e arquivos. O acesso a cada registro é controlado por regras no próprio banco, conforme o cadastro do colaborador.

Compartilhamento com terceiros

Não compartilhamos dados pessoais com terceiros, exceto o provedor de infraestrutura necessário para o funcionamento do app (Supabase).
